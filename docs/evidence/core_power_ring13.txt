1. 电压映射（决定哪些 pad 电源能进 core）
-----------------------------------------
core 是 1.8V 数字核心，其内部 PDN 只有两个 net：
  VPWR（1.8V 核心电源） <- 对应 pad 侧 VCCD / VCCHIB（1.8V）
  VGND（核心地）        <- 对应 pad 侧 VSSD / VSSA（地）
VDDIO / VSSIO 是 3.3V IO 电源，禁止接入 core（过压烧毁）。

2. core PDN 几何（从 ctsfix3 DEF SPECIALNETS 解析，dbu=0.001）
--------------------------------------------------------------
DEF：/home/user/openlane-rootfs/designs/sha256_v7b/runs/ctsfix3/results/final/def/sha256_axil.def
core 内 met5 横向 stripe（x5.28–634.58，宽 1.6），各 4 条：
  VPWR y = 27.53 / 180.71 / 333.89 / 487.07（local）
  VGND y = 30.83 / 184.01 / 337.19 / 490.37（local）
两网交替，纵向间隔 3.3。实例偏移 OFF=892.5，故全局：
  VPWR 最低 stripe 中心 y=920.03；VGND 最低 y=923.33。
解析结果存 /tmp/core_pdn_met5.json（脚本逻辑内联，可从 DEF 重跑）。

3. 实现的图形（build_chip13.py，共新增 1456 个）
------------------------------------------------
met4 1445 = 1440 缝桥接 + VPWR ring 4 边 + core VPWR 横条 1
met5    7 = VGND ring 4 边 + core VGND 横条 1 + N 边出线竖条 2
via4    4 = core VPWR 1 + VCCD 出线 2（pin + ring）+ VSSD 出线 1（pin）
  VPWR ring（met4）：中心线 x/y 862 与 1563，线宽 1.6
  VGND ring（met5）：内缩 8，中心线 x/y 870 与 1555，线宽 1.6
  N 边出线（中部 gpiov2，x 原点 1172）：
    VCCD pin(met4) -> via4 -> met5 竖条 -> via4 -> VPWR ring 顶(y1563)
    VSSD pin(met4) -> via4 -> met5 竖条 -> VGND 顶(y1555，同层免 via)
  core 左侧连接：
    VPWR met4 横条(862–900) + via4(898.6…) 上接 core VPWR met5 stripe
    VGND met5 横条(870–900) 同层接 core VGND stripe
设计要点：met5 竖条在每个 via 纵向两端外伸 0.35、横向包 0.4，
满足 m5 包 via4 0.31；via 0.8 完全落在对侧 met4 pin/ring 内（包 >=0.19）。

------------------------------------------
