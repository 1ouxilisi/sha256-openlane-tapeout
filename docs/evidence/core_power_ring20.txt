一、问题
----------------------------------------------------------------
chip19 已确认原拓扑下 met5 VGND 环宽上限为 9.8 um：限制来自 S 边
VCCD（VPWR）出线 met5 竖条与 VGND 环的同层间距，不是宽度规则。
chip20 不改环中心线、W4=2.9，只改 S 边出线拓扑，目标让 W5=10.0
flat DRC 通过。

二、拓扑改动（唯一实质变化）
----------------------------------------------------------------
原 S 边 VCCD met5 竖条：x 1549.6..1551.2，顶端
  VY0+h4+0.05 = 862+1.45+0.05 = 863.5。
新顶端常量 STRIP_TOP = 862.75（在 0.005 网格上）：
  - 保留 y=862 的 via4（box y 861.6..862.4），竖条对 via4 上方留
    0.35 um met5 包围（m5.3 要求 0.31）。
  - via4 把竖条接进 met4 S 环带（环带 y 860.55..863.45，x 罩住
    1549.6..1551.2，同属 VPWR 网络）。
新间距 = 865.0 - 862.75 = 2.25 um >= 1.6（m5.2）。
N 边 W5=10 时间距恰为 1.6，保持不动。

三、构建与并查集验证
----------------------------------------------------------------
新增图形数仍为 1470（met4 1448 / met5 12 / via4 10），
GDS 88,236,352 B。
并查集保持两个独立分量：
  VPWR 侧：4 VPWR stripe + N/S VCCD + 4 段环
  VGND 侧：4 VGND stripe + N/S VSSD + 4 段环
两网无短路，N/S 四个 pad pin 各自归入正确网络。

七、剩余边界
----------------------------------------------------------------
1. N 边仍是旧拓扑：gap = 6.6 - W5/2（竖条底 1561.6，环顶
   1555+W5/2），W5>10 须同样改 N 边出线拓扑。
2. 即使 N/S 出线都改，met5(VGND) 环与 met4(VPWR) 环在不同层、
   不同网络，环带在 W5>13.1 时跨层重叠（左：870-W5/2 < 863.45），
   那是物理短路边界，需移动环中心线才能突破。
3. 本 deck 无 m5 max width / slotting 规则，仍是 deck 覆盖缺口；
   本实验不宣称 signoff。
4. 仍无电流预算数据，方数下降只证明电阻余量变大，不能替代带
   SPEF 的功耗/IR 分析。
