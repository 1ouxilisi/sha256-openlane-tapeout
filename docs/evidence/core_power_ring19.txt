一、问题
----------------------------------------------------------------
chip16 把 met5 VGND 环保守选在 3.2 um。需要回答：met5 环到底能
加多宽？上限由什么规则决定？

二、先纠正一个前提：本 deck 没有 m5 max width 规则
----------------------------------------------------------------
通读 sky130A_flat.lydrc 中 m5 全部规则，只有：
  L661 m5.width(1.6)            m5.1  最小宽度 1.6 um
  L663 m5.space(1.6)            m5.2  最小间距 1.6 um
  L665 via4.not(m5)             m5.via4
  L666 m5.enclosing(via4,0.31)  m5.3  via4 包围 0.31 um
  L899 m5.ongrid(0.005)         m5_OFFGRID
  L900 m5.with_angle(0..45)     m5_angle
（另有 L408 vpp.5c 密度规则，本 flat 流程 vpp 为空，不触发。）

对比 m4 在 CU 分支有 L644 m4.sized(-5).sized(5) 的 10 um slotting
规则；m5 没有任何对应条目。因此「met5 max width 10 um」不是本
deck 的规则，10.0 只是 sky130 手册口径的参考值。本 deck 下的真
实上限只能靠同层间距实测。

五、chip18（10.0）：新增 2 条 m5.2，位置在 S 边
----------------------------------------------------------------
对 chip17 集合差：新增 2，消失 0，全部为 m5.2：
  edge-pair: (1549.6,863.5;1551.2,863.5)
             |(1551.757,865;1549.043,865)
  edge-pair: (1549.6,863.5;1551.2,863.5)
             |(1551.757,865;1550,865)

几何关系：
  S 边 VCCD 出线的 met5 竖条（x 1549.6..1551.2）属于 VPWR 侧，
  顶端停在 VY0+h4+0.05 = 862+1.45+0.05 = 863.5。
  VGND 下环带（W5=10）底边在 870-5 = 865.0。
  同层间距 = 865.0 - 863.5 = 1.5 um < 1.6 um → m5.2。
N 边对应位置：竖条起点 1561.6，上环带顶边 1560，间距 1.6，
恰好不触发，故只有 S 边两条。

六、chip19（9.8）：回到 22019，边界确认
----------------------------------------------------------------
间距公式：gap = 870 - W5/2 - 863.5 = 6.5 - W5/2
要求 gap >= 1.6 → W5 <= 9.8。
W5=9.8 时环带下沿 865.1，gap = 1.6，实测：
  TOTAL 22019，对 chip17 集合差新增 0 / 消失 0。
环宽实测：
  met5 左环 x 865.100..874.900 = 9.800 um
  met5 右环 x 1550.100..1559.900 = 9.800 um
结论：9.8 通过、10.0 失败，本拓扑下 met5 环宽上限 = 9.8 um，
限制来自 S 边 VPWR 出线竖条与 VGND 环的同层间距，不是 max width。

八、结论与边界
----------------------------------------------------------------
1. met5 VGND 环可从 3.2 一路加到 9.8 而 flat DRC 不增加任何条目；
   推荐工程值取 9.8（chip19），留整口径可写「接近 10 um」。
2. 10.0 的失败是同层间距 1.5 um，不是宽度超限；若要突破，必须
   改 S 边出线拓扑（如缩短竖条或换层），属于改设计而非改参数。
3. 本 deck 无 m5 max width / slotting 规则，这是 deck 覆盖缺口；
   真实流片若依赖宽金属 slotting，需补规则或换完整厂商 deck，
   本实验不宣称 signoff。
4. 仍然没有电流预算数据，方数下降只能证明电阻余量变大，不能
   替代带 SPEF 的功耗/IR 分析。
