一处自我更正（留在明面上，不抹掉）：
  上一版把 81/14 写成「prBoundary」——写错了。查 PDK 图层名表：prBoundary 是 235/4，81/14 是 areaid.lowTapDensity。
  结论不变（81/14 同样是不参与制造的 flow 标记层，流水线第 37 步也用 -rd ignore=81/14 排除它），但层名以这一版为准。

结论：
- 21 个制造层（nwell / diff / tap / poly / licon1 / li1 / mcon / met1–met5 / via–via4 / hvtp / nsdm / psdm / npc）
  几何覆盖全部一致，XOR 全为 0。
- 全部 layer/datatype 42 层里，只有 areaid.lowTapDensity（81/14）差 1 个多边形：A 有 1 个，B 有 0 个；
  该层是 flow 标记，不参与制造，流水线本身也把它排除在外。
- 因此「两份 GDS 逐层一致」这句话，可以改成更准确的一句：
  「21 个制造层全部一致；42 个层里唯一差异是一个不参与制造的 flow 标记层」。

局限：
- 这是 run 结束后补做的比对，不是流水线第 37 步当时的产物；同库（KLayout 0.29.1）、同一对 GDS。
- KLayout 的 Ruby DRC 引擎在本机 chroot 里初始化即崩（tlFileUtils.cc:979），所以 Magic / KLayout 的
