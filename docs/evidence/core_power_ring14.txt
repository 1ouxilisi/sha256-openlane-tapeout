3. 端到端连通性（verify_chip14.py，并查集，硬证据）
==================================================================
方法：clip 区域 x855–1590 / y150–2280 内 merge met4、met5，同层重叠合并；
      再对每个 via4 取中心点，连接其所在的 met4 多边形与 met5 多边形；求连通分量。
（同层已 merge 成互不重叠多边形，故跨层只可能经 via4 连通，此模型与版图等价）

结果：
  VPWR 分量数 1   → 4 条 VPWR stripe + N VCCD pin + S VCCD pin 同一网络     PASS
  VGND 分量数 1   → 4 条 VGND stripe + N VSSD pin + S VSSD pin 同一网络     PASS
  VPWR ∩ VGND = ∅ → 无短路                                                  PASS
  N VCCD → VPWR stripe   True
  S VCCD → VPWR stripe   True
  N VSSD → VGND stripe   True
  S VSSD → VGND stripe   True

5. S 边出线的工程口径（不夸大）
==================================================================
- 出线竖条宽 1.6 µm、长约 675 µm（187.6→862.75 / 155.1→870.0），
  按设计规则只能做到 met5 最小宽度（m5 width 1.6），因此这一版是
  "拓扑闭环 + 几何合法"的演示，不是产品级 PDN：
  竖条自身方块数约 675/1.6 ≈ 422 方，串联电阻需按 PDK met5 片电阻复核后
  才能给 IR drop 结论——本文不给电阻/压降数字。
- 与 N 边相比，S 边竖条起点更低（y155/187 vs y2269），长度相近，
  两条出线并联后 core 最低 stripe 到 pad 的路径电阻约降一半（定性，
  未用电学工具验证）。
- 真正的低阻做法需要加宽出线到 4–6 µm 或多打几个出线点，
  加宽会撞 VGND 环右侧条（x1554.2–1555.8），需重排环间距——列为后续。
