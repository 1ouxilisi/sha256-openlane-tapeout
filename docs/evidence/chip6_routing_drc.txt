# 96 路信号接线 + 含 core 合并 DRC：零新增违例收口证据

## 1. 目标与边界

把 ctsfix3 标准流程 core（640×640，top sha256_axil，153 cells）的 96 个信号引脚
接到 100 pad 框架（die 2425×2425，96 个 gpiov2 + 4 个电源 pad）的 96 个对应 pad 入口，
合并成一个完整 top，并用 KLayout 全规则 DRC 验证。

本证据只覆盖 96 路信号。电源/地六网（VDDIO/VSSIO/VCCD/VSSD/VDDA/VSSA）的
core 到电源 pad 连接不在本件范围内，另行处理。

## 2. 数据与几何事实

- 96 信号：55 INPUT（pad 侧 IN，met3 引脚，入口截面宽 0.33 µm），
  41 OUTPUT（pad 侧 OUT，met2 引脚，入口截面宽 1.56 µm）。
- core pin 层：met3 79 个、met2 17 个；边分布 E41、W39、S15、N1。
- 分配：core 偏移 892.5（居中），全局曼哈顿贪心 96 路全分配，
  54 同边 / 42 跨边；曼哈顿距离中位 1165.5 µm，最大 2422.4 µm。
- 环缝：met2/met3 双环在 96 个信号位置各切 1.1 µm 缝（HALF=0.55），
  信号单层直穿、环上无 via。
- 四条 band 独立 track（1.0 µm 间距，避开固定端点 0.5）：
  LB 用 43 track、RB 44、BB 27、TB 26。
- 本次接线新增 via2 共 288 个（cut 0.26，0.4 enclosure），
  水平常规走 met2、竖直常规走 met3，宽 0.4；入口段按 pin 精确截面画。

## 3. 关键工程决策（避免再走回头路）

1. pin 截面必须用真实几何，不能统一 0.4。探针实测 55 个 met3 pin 宽 0.33、
   41 个 met2 入口条宽 1.56；统一 0.4 会在 0.33 pin 处产生 0.2 宽窄颈。
2. via 只在相邻段层不同处加。同层相邻（如 S 入口 met2 接 BB 横 met2）
   不加 via，否则会留下孤立 0.4×0.4 met3 方块（面积 0.16 < 0.24，m3.6）。
3. 入口段与首段都要外伸 0.2 µm 覆盖对方 0.4 宽走线，
   否则 L 形交接处出现窄颈（m3.1）或 0.09 间隙（m2.2）。
4. deep 模式对环缝碎片化版图病理化（57 分钟不收敛），
   改用 flat 模式 + 独立 padring flat 基线做差。

## 4. DRC 收敛过程（flat 模式，全规则，threads 4）

独立 padring flat 基线 TOTAL = 22019。

## 6. 口径说明

- 剩余 22019 全部是 padring 自身几何基线（含每 gpiov2 一个、共 96 个
  m2_OFFGRID，已证实来自 pad 斜边几何本身，与接线无关）。
- 这不等于「全片 DRC 清零」：padring 基线本身在 flat 模式下按实例重数
  放大计数；deep 模式下独立 padring/tie v5 的真实违例为 514。
- pad 级 LVS 受 netgen devices 表限制判不了，接线正确性靠几何 +
  网表人工核对；本件不声称 pad 级 LVS 通过。
