CORE POWER RING 第八版（chip25）证据
==============================================
日期：2026-11-16
对象：sha256_chip25.gds（W5=16.9，整条电源环向 die 边整体外移 20 um）
基线：sha256_chip23.gds（W5=16.9，环中心线 872/1553，环在 862/1563）
目的：上一版（chip23/24）把「加宽环」这条路走到了内移中心线 16.9 的头；按上一版证据第八节，
      剩下唯一没动过的变量是「把电源环从 core 周边整体外移」。本轮做一次真实外移，
      验证三件事：环能不能整体搬走、出线/via4 要不要跟着动、外移后 DRC 与连通性是否保持。

一、设计变更（一次整体平移，宽度与层间关系全部不变）
----------------------------------------------
1) 外移量 SHIFT = 20.000 um。四条边整体向 die 边平移：
   VPWR 环（met4）中心线 左/下 862.000 -> 842.000，右/上 1563.000 -> 1583.000；
   VGND 环（met5）中心线 左/下 872.000 -> 852.000，右/上 1553.000 -> 1573.000。
   met4 与 met5 中心线仍相差 10.000 um，宽度 W4=2.9、W5=16.9 完全不变。
2) 出线整组随环平移，否则 via4 会掉出环带：
   S 边 via4 中心 861.200 -> 841.200，met5 竖条顶端 861.950 -> 841.950；
   N 边 via4 中心 1563.800 -> 1583.800，met5 竖条底端 1563.050 -> 1583.050。
   8 条 core stripe 朝环方向延长（起点随环外移 20，终点仍到 900/1525），y 坐标不变。
3) 1440 条缝桥（met4）固定不动 —— 它们在 pad 缝里，不属于电源环。

二、外移后约束为什么一条都没破（本轮核心）
----------------------------------------------
上一版的闭合式 gap = (G0 - W5/2) - strip_end >= 1.60，本轮把 G0 和 strip_end 同时减 SHIFT：
   (G0 - SHIFT - W5/2) - (861.95 - SHIFT) = 原值 1.60，SHIFT 被消掉。
所以 m5.2 的 1.600 间距在外移后原样保留，与外移量无关 —— 只要出线竖条跟着环一起走。
跨层间隙同理：met4 环外沿 843.450、met5 环外沿 843.550，仍差 0.100。
结论：外移是一个「免费」的位置自由度，它不改变任何间距/包围，只改变环与 core 之间的通道。

三、构建结果
----------------------------------------------
GDS 88,236,352 B，新增 1470 个图形（met4 1448 / met5 12 / via4 10），与 chip23 字节、图形数完全一致。
缝桥仍为 1440 条（/tmp/pwr_bridges.json）。

实测（y=1200 切片，dbu=0.001）：
  met5 左环 x 843.550-860.450 宽 16.900；右环 x 1564.550-1581.450 宽 16.900
  met4 左环 840.550-843.450 -> 跨层间隙 0.100；met4 右环 1581.550-1584.450 -> 0.100
  met5 环内沿 860.450 / 1564.550，距 core 边（892.5 / 1532.5）各 32.050（chip23 为 12.050）
  met4&met5 重叠多边形 1301 个，面积 99,933.0 um2（chip23 同为 1301 / 99,933.0）

四、连通性核验（klayout.db，clip 835-1612 / 150-2280）
----------------------------------------------
  met4 单网络 True、met5 单网络 True、两网无短路 True
  N/S VCCD -> VPWR True、N/S VSSD -> VGND True
  S 竖条顶 841.950，ring 底 843.550，gap 1.600
  N 竖条底 1583.050，ring 顶 1581.450，gap 1.600
  S via4 上包围 0.350、N via4 下包围 0.350（m5.3 要求 0.31）

五、flat DRC
----------------------------------------------
chip25：22019（总耗时 1690.130 s），七类分布与 chip23 逐条相同
        m1.3ab 8924 / m3.3ab 6173 / m2.3ab 4469 / m4.5ab 1968 / m2.2 242 / m1.2 147 / m2_OFFGRID 96
        与 chip23 集合差：新增 0 / 消失 0（各 21995 条唯一坐标）。
即整环外移 20 um 没有产生或消除任何一条 DRC，22019 全部来自 pad 斜边与 core 固有项。

六、外边界在哪（解析，未实测）
----------------------------------------------
环带 y 范围（842-1583）内，左侧最内固定结构只到 x=197.965，即环外移在该区间内没有障碍；
真正伸得最深的是四角缝桥链（到 x=848.94），但它们落在 y 143-152 / 2272-2281，
与环带 y 不重叠，所以环外沿在 S=20 时（840.55）虽已越过 848.94 这个 x，仍不接触。
继续外移，环要到外沿逼近 pad 内边（W/E pad x=200、N/S y=200）或四角缝桥链时才到边界，
对应 SHIFT 约 640-710，那时环已进入 pad 区域、没有工程意义，与上一版内边界 29.05 对称。
故外移的可用区间很宽，本轮 SHIFT=20 取的是「把环内通道从 12.05 恢复到 32.05」这个工程点。

七、口径边界（不变）
----------------------------------------------
不写 signoff，只写「flat DRC 22019 与基线逐条相同、集合差 0/0」。
本 deck 没有 m5 max width / m5 slotting 规则，这是覆盖缺口，不因此认定 16.9 um 宽 met5 合法可制造。
仍无任何电流预算数据（活动率/向量集/带 SPEF 的 IR）；外移只改变几何通道，不替代功耗与 IR 分析。
环半尺寸由 701 变为 741、出线竖条缩短 20，单入口绕行路径随之变化，本轮不重算方数；
W5=16.9 的局部电阻口径与 chip23 一致。
