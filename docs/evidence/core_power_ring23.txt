CORE POWER RING 第七版（chip23 / chip24）证据
==============================================
日期：2026-11-16
对象：sha256_chip23.gds（W5=16.9，VGND 环中心线内移 2 um）
      sha256_chip24.gds（W5=17.0，同拓扑，边界失败版）
基线：sha256_chip22.gds（W5=12.9，环中心线 870/1555 未动）
目的：把 chip22 那条「不动环中心线时 met5 环宽上限 12.9」的口径，改成一次真实设计：
      移动环中心线，看上限到底跟着动多少，以及动它要付什么代价。

一、设计变更（只有两件事）
----------------------------------------------
1) VGND 环（met5）四条边的中心线整体内移 2.000 um：
   左/下 870.000 -> 872.000，右/上 1555.000 -> 1553.000。
   VPWR 环（met4）中心线 862/1563、宽度 2.9 完全不动。
   8 条 stripe 的 y 坐标、S/N 边出线竖条与 via4 位置全部沿用 chip22。
2) met5 环宽 W5：chip23 = 16.9，chip24 = 17.0。

二、约束从哪里来（本轮最重要的结论）
----------------------------------------------
环越宽，它朝 die 边的那条外沿越贴近 S/N 边出线竖条；两条都是 met5，受 m5.2 1.6 um 间距约束。
出线竖条的端点是被 via4 钉死的：via4 必须在 met4 环带（860.55-863.45，高 2.90）内，
两侧各留 0.19（via4.4），met5 竖条还要再包住 via4 顶点 0.31（m5.3）。
chip22 已把 S 竖条顶定在 861.95、N 竖条底定在 1563.05，这是这组约束下能到的位置。

于是上限是一条一元式子：
   gap = (G0 - W5/2) - 861.95 >= 1.60     (S 边，G0 为 VGND 环下边中心线)
   => W5 <= 2 * (G0 - 863.55)
   => W5max = 2 * (6.45 + Δ)，Δ 为环中心线内移量
   Δ=0 -> 12.9（chip22）；Δ=2 -> 16.9（chip23）；Δ=2 时 17.0 即 1.55（chip24 失败）

同一条式子同时解释了跨层：环外沿被 1.6 顶在 863.55 时，离 met4 环外沿 863.45 恰好 0.100；
所以 W5 怎么变，跨层间隙都还是 0.100 —— met4 从来不是瓶颈，出线位置才是。

六、口径更正（重要，覆盖 chip22 那一节的一句）
----------------------------------------------
chip22 的证据与页面写过「met5 环内沿 870-W5/2 与 met4 环外沿 863.45 在 W5=13.1 相切，
>13.1 几何重叠 = 两网短路」。这句不准确，本轮给出更正：
1) met4 与 met5 是不同层的两块金属，面积重叠不构成连通，短路只发生在同层接触或 via4 错接。
   实测 chip22/23/24 三版 met4&met5 重叠多边形都是 1301 个（面积 99907.4 / 99933.0 / 99933.6 um2），
   而连通性核验里两网依旧分离 —— 说明这类重叠从 chip13 起就一直存在，且不短路。
2) 因此 12.9/13.1 这条线不是电学边界，而是两条东西混在一起：DRC 上的 m5.2（1.6）由出线竖条给出，
   版图意图上的「不把 met5 环压到 met4 环上」由 863.45 给出。前者先到（12.9），后者晚 0.2 um（13.1）。
3) 正确表述：不动中心线时 met5 环宽上限 12.9 是 m5.2 给的，met4 那条是设计者自己加的余量线。
   旧文保留不改，以本节为准。

七、方数（单入口绕行 1402 um，L/W）
----------------------------------------------
W5=1.6 -> 876.25 方   12.9 -> 108.68   16.9 -> 82.96   17.0 -> 82.47
从 12.9 到 16.9 再降 23.7%；相对 1.6 基线累计降 90.5%。

八、下一步的边界在哪（解析，未实测）
----------------------------------------------
把上限定死在 core 边上（环内沿贴 core 892.5 / 1532.5），G0 最多 877.975，对应 W5 约 29.05；
但那时环已经贴着 core 边界、没有布线通道，工程上不可用。
真正还有意义的动作不是继续加宽环，而是三者联动：出线位置（受 via4 在 2.90 高 met4 环带内的
0.19+0.31 夹住，理论只能再下移约 0.06）、环中心线、以及把电源环从 core 周边整体外移。
单纯推 W5 这条路，在 Δ=2 之后开始迅速失去意义。

九、口径边界（不变）
----------------------------------------------
不写 signoff，只写「flat DRC 22019 与基线逐条相同」。
本 deck 没有 m5 max width / m5 slotting 规则，这是覆盖缺口，不因此认定 16.9 um 宽 met5 合法可制造。
仍无任何电流预算数据（活动率/向量集/带 SPEF 的 IR），方数下降只说明电阻余量变大，
不能替代功耗与 IR 分析。
