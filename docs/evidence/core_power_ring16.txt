sha256_chip16 —— core 电源环加宽的极限在哪里
=================================================
生成时间：2026-11-15（vm）
基线：sha256_chip6.gds（100 pad + 1440 缝桥那一版）
上游：chip13（环 1.6 + N 出线）、chip14（+8 条 stripe + S 出线）
本版：环宽从 1.6 抬到 VPWR met4 2.9 / VGND met5 3.2，拓扑不变

一句话结论
----------
加宽环是唯一「不要 IO 代价」的杠杆，但它有硬顶：met4 环超 3.0 µm 会撞 m4.5ab，
因此 VPWR 停在 2.9、VGND 可到 3.2；这一版的 flat DRC 与 chip14 **逐条相同**（22019）。


一、两个版本
------------
chip15：met4 3.2 / met5 3.2
  TOTAL 22023，比 chip14（22019）**多 4 条，全部是 m4.5ab**
  flat 用时 2286.190 s

chip16：met4 2.9 / met5 3.2
  TOTAL 22019，类别逐项与 chip14 一致：
    m1.3ab 8924 / m3.3ab 6173 / m2.3ab 4469 / m4.5ab 1968 / m2.2 242 / m1.2 147 / m2_OFFGRID 96
  逐条比对：**新增条目 0，消失条目 0**（按 category + 边坐标做集合差）
  flat 用时 2281.610 s

两版 GDS 都是 1470 个新图形（met4 1448 / met5 12 / via4 10），字节数都是 88,236,352 B
（差在环的尺寸，不在图形数）。


二、那 4 条新增在哪
------------------
chip15 相对 chip14 新增的 4 条，坐标全部落在 x = 863.6 —— 也就是 3.2 宽环的内沿
（环 860.4..863.6）；y 区间正好罩住 4 条 VPWR 横条的上下沿（±0.8）与外沿（±1.2）：

  m4.5ab (863.6, 918.83..921.23) / (863.6, 919.23..920.83)     ← 横条 y=920.03
  m4.5ab (863.6, 1072.01..1074.41) / (863.6, 1072.41..1074.01) ← 横条 y=1073.21
  m4.5ab (863.6, 1225.19..1227.59) / (863.6, 1225.59..1227.19) ← 横条 y=1226.39
  m4.5ab (863.6, 1378.37..1380.77) / (863.6, 1378.77..1380.37) ← 横条 y=1379.57

规则出处：`sky130A_flat.lydrc` L630，`huge_m4 = m4.sized(-1.5).sized(1.5)`，
宽 > 3 µm 的 met4 与邻居要 0.4 µm 间距。
机制上：环宽 3.2 时「宽金属」形态存在，环与横条合并处的边被这条规则判成 0 间距；
环宽 2.9 时 `sized(-1.5)` 之后为空集，整条规则不触发 —— 所以 chip16 一条不多。

met5 侧没有同类规则（deck L661/L663 宽 1.6、间距 1.6；L644 max width 10.0），
所以 VGND 环 3.2 是零代价；chip15 的 +4 里没有一条 m5 类，这一点被实测确认。


三、连通性（并查集，clip 取 855..1592 / 150..2280）
---------------------------------------------------
探针 12 个：4 条 VPWR stripe（y 920.03/1073.21/1226.39/1379.57）、4 条 VGND stripe
（y 923.33/1076.51/1229.69/1382.87）、N/S 各两个电源 pad 的 met4 pin、VPWR 环四段中点、
VGND 环四段中点。

结果：
  VPWR 侧分量数 1 —— 8 条 stripe + 4 段环 + N VCCD pin + S VCCD pin 同一网络
  VGND 侧分量数 1 —— 8 条 stripe + 4 段环 + N VSSD pin + S VSSD pin 同一网络
  VPWR 与 VGND 无短路
几何实测：met4 环竖段 x 860.55..863.45（2.90），met5 环竖段 x 868.40..871.60（3.20），
四段环的端点均随外沿同步外扩，S/N 出线的 met5 竖条端点跟着环外沿走，仍与环相并。


四、方数量化（只是几何，不是电阻）
----------------------------------
环边长度：VPWR 701 µm（中心线 x/y 862、1563），VGND 685 µm（870、1555）。
单入口（只 N 边或只 S 边）时，到最远端要绕 1402 µm：

  环宽 1.6（chip13/14）：1402 / 1.6 = 876 方
  环宽 2.9（chip16 VPWR）：1402 / 2.9 = 483 方
  环宽 3.2（chip16 VGND）：1402 / 3.2 = 438 方
  环宽 2.9 + 双入口（W/E 各补一个）：1402 → 701，701 / 2.9 = 242 方

对照：环 → stripe 的接头只有 6.75 方（VPWR 4 条 × 27 方并联）/ 4.7 方（VGND 4 条 × 18.75 方并联），
仍是可忽略的一档。所以这一版把「环上绕行」从 876 方压到 483/438 方，约 1.8–2.0 倍，
代价是 0 条新 DRC、0 个 IO。


五、这一版仍然不成立的判断
--------------------------
- **不给电阻和压降数字。** PDK `Metal 4/5 RESOVER` 表只有一列 0.000156667，量纲不明；
  `metrics.csv` 的功耗字段合计约 0.0095 µW（≈5 nA @1.8 V），是默认活动率估计，不能用来定容。
  所以这里只能说「方数变少」，不能说「压降从 X 降到 Y」。
- **零新增 DRC 不是 signoff。** flat 22019 里 7 类存量一条没动（m1.3ab/m3.3ab/m2.3ab 等），
  只是没有新增；pad 级 LVS 在本环境仍判不了（netgen `sky130A_setup.tcl` 第 378 行只认两种 IO cell）。
- **W/E 边没有补电源 pad。** 加宽环解决的是「环上绕行」，不是「入口冗余」；
  两者叠加的算账见 `docs/evidence/w_e_power_pad_tradeoff.txt`。
